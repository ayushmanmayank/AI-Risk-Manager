# razorpay-track-2-
# AI Risk Manager — Merchant Fraud Detection

Day 1 of a Razorpay AI Hackathon project. This repository builds and evaluates
a temporally split fraud classifier using the Kaggle credit-card-fraud dataset.

## Day 1 scope

Build the data validation, feature engineering, and validation-only training
pipeline. The test set is intentionally held out.

## Expected dataset

Place `creditcard.csv` at `data/raw/creditcard.csv`. Raw CSV files are not
tracked by Git.
